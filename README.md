Ce dépôt contient les fichiers compilés du site de démonstration de rl-docx-editor, la bibliothèque RLDEV.

rl-docx-editor est un éditeur de modèles Word dans le navigateur : les variables, boucles, conditions et images se placent par glisser-déposer.

Le site comprend une page de présentation et une page Démo : jusqu'à 3 modèles (facture, devis, attestation), gardés dans le navigateur, modifiables dans l'éditeur, remplis avec un formulaire puis convertis en PDF, sans serveur.

Démo : https://rleditor.rayanlaffi.fr/
